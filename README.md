# ThreeQ

A clear, musical 3-band equalizer plugin, built with [JUCE](https://juce.com/).

## Features

- **Low Shelf** — 20 Hz–500 Hz, ±24 dB
- **Mid Peak** — 200 Hz–8 kHz, ±24 dB, adjustable Q (0.1–10)
- **High Shelf** — 2 kHz–20 kHz, ±24 dB
- Custom GUI with a slider per parameter
- Formats: **VST3**, **AU**, and **Standalone**

## Requirements

- macOS with Xcode
- [JUCE](https://juce.com/) framework installed locally

## Building

1. Open `ThreeQ.jucer` in **Projucer** and click **Save Project** (this regenerates the Xcode project and `JuceLibraryCode/`).
2. Open the generated project in Xcode:
   ```
   Builds/MacOSX/ThreeQ.xcodeproj
   ```
3. Build the target you want (`ThreeQ - VST3`, `ThreeQ - AU`, or `ThreeQ - Standalone Plugin`) in **Release** configuration.

A successful Release build automatically installs the VST3/AU into:
```
~/Library/Audio/Plug-Ins/VST3/
~/Library/Audio/Plug-Ins/Components/
```

### Validating the AU

```
auval -v aufx Q3eq Mkli
```

## Project structure

```
Source/
  PluginProcessor.h/.cpp   DSP: 3-band filter chain (Low Shelf / Peak / High Shelf)
  PluginEditor.h/.cpp      GUI: sliders bound to plugin parameters
ThreeQ.jucer               Projucer project definition (source of truth for build config)
JuceLibraryCode/           Generated by Projucer, tracked in git
Builds/                    Generated Xcode project, not tracked in git
```
